X3D CCD 亲和度管理器 1.0.2
==========================

系统要求
--------
- Windows 10 1809 或更高版本
- 64 位 Windows
- 不需要单独安装 .NET

免安装版使用方法
----------------
1. 解压整个目录。
2. 运行 CcdAffinityManager.exe。
3. 添加游戏进程或游戏 EXE，确认亲和度为大缓存 CCD。
4. 点击“启用监控”。

安装版使用方法
--------------
1. 运行 CcdAffinityManager-Setup-1.0.2.exe。
2. 按向导完成安装，可选择是否创建桌面快捷方式。
3. 从开始菜单或桌面启动程序。

权限说明
--------
- 程序启动时会请求管理员权限，以启用事件驱动检测。
- Windows UAC 会显示一次确认提示，这是 Windows 的安全机制。
- 安装程序本身不需要管理员权限。

规则缓存
--------
规则保存在：
%LOCALAPPDATA%\CcdAffinityManager\settings.json

卸载
----
- 安装版可从“设置 > 应用”或开始菜单中的卸载入口卸载。
- 卸载程序不会删除上述规则缓存；如需彻底清理，可手动删除该目录。

Windows 提示
------------
当前发布文件未使用商业代码签名证书。Windows SmartScreen 可能显示
“Windows 已保护你的电脑”。确认文件来源可信后，可点击“更多信息”并选择
“仍要运行”。

分享建议
--------
- 对方只想直接使用：发送免安装版 ZIP。
- 对方需要开始菜单、桌面快捷方式和卸载入口：发送安装版 EXE。
- 新版本可以直接覆盖安装，规则缓存不会丢失。

启动时绑定
----------
- 启用监控后，从本工具点击“启动程序”会在目标进程运行前设置亲和度。
- 该方式使用 Windows 标准的挂起创建流程，不注入进程、不修改内存、不安装 Hook。
- 反作弊策略由游戏厂商决定；受保护进程能否设置亲和度最终取决于其内核保护。
